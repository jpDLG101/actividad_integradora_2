# Actividad Integradora 2 — Servicios de Internet

Programa en Python que ayuda a una empresa que quiere ofrecer servicios de Internet en una ciudad. Usa solo la biblioteca estándar.

| Parte | Resultado | Algoritmo |
|---|---|---|
| 1 | Forma óptima de cablear las colonias con fibra óptica | Prim (avaro) |
| 2 | Ruta más corta del repartidor que visita cada colonia y regresa al origen | Ramificación y poda |
| 3 | Flujo máximo de información del nodo inicial al final | Ford-Fulkerson |
| 4 | Central más cercana a una nueva contratación (polígonos) | Pendiente de verse en clase |

## Ejecución

```bash
python3 src/main.py examples/entrada1.txt
```
